# Stage 1 administration interface

Use the name Knowledge AI. This is a working enterprise tool for product/project owners, contributors and readers.

Visual direction: white work surfaces, slate navigation, deep navy text, restrained crimson action/accent inspired by the architecture reference without reusing its corporate marks. Use system sans-serif for prose and monospace only for version/revision identifiers. No decorative marketing hero.

Navigation: Profiles, Knowledge Models, Review Inbox, Central Graph, Ask Knowledge AI, Activity. Show current user and role, selected profile/version, and clear publication status.

The signature screen is an evidence-backed review workspace: selected candidate on the left, source excerpt and page/chunk reference on the right, exact revision above approval actions. Keep Draft, Approved — awaiting publication, Blocked, Published and Publication failed visibly distinct.

All primary workflows must be usable through the UI: administration of users/owner assignments/read grants; profile and version creation; model drafts and publication; manual upload; draft edits; explicit owner review; publication; graph inspection; cited questions; version release; source-change proposals and activity.

Empty states should tell the user the next available action. Do not populate invented products, documents or facts in the production database. Automated test fixtures stay in test profiles and are removed or clearly marked as test data after validation.
